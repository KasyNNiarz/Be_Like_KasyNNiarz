Be_Like_KasyNNiarz — wersja 1.0

CO TO JEST
Lekka, mobilna aplikacja webowa przygotowana do używania na Androidzie w przeglądarce Chrome. Dane zapisują się lokalnie w przeglądarce (localStorage). To prototyp webowy, a nie jeszcze natywna aplikacja APK.

JAK URUCHOMIĆ NA ANDROIDZIE — NAJPROŚCIEJ
1. Otwórz plik index.html na komputerze albo umieść folder na hostingu statycznym (np. GitHub Pages / Netlify).
2. Otwórz adres strony w Chrome na telefonie.
3. Menu Chrome (⋮) → „Dodaj do ekranu głównego” lub „Zainstaluj aplikację”, jeśli opcja jest dostępna.
4. Korzystaj z zakładek na dole. Postępy są zapisywane w tej przeglądarce na tym urządzeniu.

WAŻNE: Samo otwarcie lokalnego pliku HTML w niektórych przeglądarkach Androida może ograniczać zapisywanie danych. Najpewniej działa po udostępnieniu przez hosting HTTPS.

FUNKCJE
- Plan: środa (góra), piątek (brzuch), sobota (dół).
- Instrukcje ćwiczeń, zakresy powtórzeń i przerwy.
- Timer serii i timer przerw; gotowe przyciski 30/60/90/120 s.
- Historia treningów, odhaczanie serii i notatki.
- Dziennik siatkówki i czas aktywności.
- Dziennik posiłków oraz zapisywanie wypitej wody.
- Kalendarz i notatki do dni.
- Dane przechowywane lokalnie; wyczyszczenie danych witryny może je usunąć.

UWAGA TRENINGOWA
Przed treningiem zrób 5–8 min rozgrzewki. Wybieraj obciążenie pozwalające zachować technikę i zostawić 2–3 powtórzenia w zapasie. Nie testuj maksymalnych ciężarów ani nie ćwicz przez ból. Przy meczu, dużym zmęczeniu lub mocnych zakwasach ogranicz/opuść sesję. Dla osoby niepełnoletniej plan i technikę warto omówić z trenerem oraz rodzicem/opiekunem.

STRUKTURA
index.html — cała aplikacja (HTML/CSS/JS w jednym pliku).
